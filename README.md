# 🚀 Getting Started

Clone the repository

```bash
git clone https://github.com/Avik0333/TaskFlow.git
```

Move into the project

```bash
cd TaskFlow
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Open

```
http://localhost:5173
```
